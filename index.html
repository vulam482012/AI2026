Sổ Tay Công Thức Toán THCS

Tổng hợp các hằng đẳng thức, hình học và đại số cốt lõi.

7 Hằng đẳng thức đáng nhớ

  • 1. (A + B)² = A² + 2AB + B²
  • 2. (A - B)² = A² - 2AB + B²
  • 3. A² - B² = (A - B)(A + B)
  • 4. (A + B)³ = A³ + 3A²B + 3AB² + B³
  • 5. (A - B)³ = A³ - 3A²B + 3AB² - B³
  • 6. A³ + B³ = (A + B)(A² - AB + B²)
  • 7. A³ - B³ = (A - B)(A² + AB + B²)

Hình học & Lượng giác THCS

  • • Định lý Pythagore: BC² = AB² + AC²
  • • Hệ thức lượng trong tam giác vuông: b² = a · b'
  • • Tỷ số lượng giác: sin = Đối / Huyền, cos = Kề / Huyền
  • • Diện tích hình tròn: S = πR²
