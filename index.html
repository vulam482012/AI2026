Sổ Tay Công Thức Toán THCS

Tổng hợp các hằng đẳng thức, hình học và đại số cốt lõi.

7 Hằng đẳng thức đáng nhớ

  • 1. $(A + B)^2 = A^2 + 2AB + B^2$
  • 2. $(A - B)^2 = A^2 - 2AB + B^2$
  • 3. $A^2 - B^2 = (A - B)(A + B)$
  • 4. $(A + B)^3 = A^3 + 3A^2B + 3AB^2 + B^3$
  • 5. $(A - B)^3 = A^3 - 3A^2B + 3AB^2 - B^3$
  • 6. $A^3 + B^3 = (A + B)(A^2 - AB + B^2)$
  • 7. $A^3 - B^3 = (A - B)(A^2 + AB + B^2)$

Hình học & Lượng giác THCS

  • • Định lý Pythagore: Trong tam giác vuông ABC vuông tại A: $BC^2 = AB^2 + AC^2$.
  • • Hệ thức lượng trong tam giác vuông: $b^2 = a \cdot b'$, $h^2 = b' \cdot c'$.
  • • Tỷ số lượng giác: $\sin = \frac{\text{Đối}}{\text{Huyền}}$, $\cos = \frac{\text{Kề}}{\text{Huyền}}$, $\tan = \frac{\text{Đối}}{\text{Kề}}$, $\cot = \frac{\text{Kề}}{\text{Đối}}$.
  • • Diện tích hình tròn: $S = \pi R^2$, Chu vi $C = 2\pi R$.
